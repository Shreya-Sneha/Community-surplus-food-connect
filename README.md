# 🍲 Community Surplus Food Connect

**Community Surplus Food Connect** is a full-stack platform engineered to bridge the gap between commercial food surplus (restaurants, cafeterias, event venues) and local welfare shelters or community kitchens to reduce urban food waste.

## 🚀 Features
- **Donor Dashboard:** Create listings for surplus meals with pickup details, portions, and expiry timers.
- **Dynamic Feed:** Real-time food listing feed filtered by status and category.
- **Shelter Claim System:** State synchronization transitioning listings from `available` to `claimed` to prevent duplicate collections.
- **Lightweight Architecture:** Asynchronous client-side UI connected to an Express.js REST API with SQLite persistence.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Backend:** Node.js, Express.js
- **Database:** SQLite3
- **Tools:** Git, GitHub, VS Code
